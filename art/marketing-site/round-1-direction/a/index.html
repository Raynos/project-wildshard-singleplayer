The world

A world made of shards.

Each shard is 500 × 500 × 500 metres, built by one author and placed on a shared grid. A server-owned highway runs between them; glowing seams stitch them together. The first grid is five by five around a fixed centre.

In engine today: Nalati Grasslands from the air, one whole shard.

How a shard is made

Claude Code is the level editor.

  1. 1Get a creator key
  2. 2Install the Wildshard skill and SDK in your own Claude Code
  3. 3Describe it. Claude builds it on a floating cube
  4. 4wildshard build and validate check every budget and edge
  5. 5Walk it locally
  6. 6Upload it in the game
