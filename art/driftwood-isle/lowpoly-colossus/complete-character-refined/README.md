## Integrated construction

cage. Four short heart clasps and two overlapping inward ribs were removed rather
than adding extra plates. The cyan crystal is seated deeper in the trunk and the
common upper-body depth expansion reduced. A longer central pale face ridge joins
broader cheek/jaw planes around larger bounded cyan eyes. The same shared shape
map brings hanging arms inward continuously, while calf and ankle anchors broaden
around existing stones. Larger growth islands and fewer, wider secondary leaves
make a broad-to-small canopy hierarchy. Bark material assignments follow a side
continuously rather than alternating at triangulated sections.

These remain overlapping closed components, not a single union-watertight sculpt.
Root intersections, subjective anatomy, appearance and motion need independent
review. A broad dark back and angular elbows remain potential visual weaknesses.

## Reproduction and evidence

Use Blender 4.3.2 with two threads and the coordinated render lease:

    blender -b -t 2 --python-exit-code 1 --python render_matched.py -- --out tmp/colossus-complete-character-refined

Run from the repository root, using this directory's full script path. The renderer
freshly builds and captures retained complete-character-next and the candidate,
using identical unchanged cameras, lights, floor, 525x700, 16 Cycles samples without
denoising, Standard transform and ortho 7.7. Ten original PNGs per version stay in
ignored tmp; labelled WebPs, matched hero board and nine-view sheets are derived
without retouching. Cameras and framing receipts expose the actual view positions.

Run validate_glb.py on the final GLB, export_native.py, then the focused consumer
test using this directory's vitest.config.ts. Run package_evidence.py after copying
candidate GLB and editable-native.json from raw capture output to this directory.
Final closure pins every publication file. Capture receipt pins all raw evidence.
Preservation receipt verifies retained source, model and prior closure unchanged.

No shared runtime, UI, State, physics, Git, Site or Mac changes are part of this pass.
