# Terminal-edge-only refinement

Separate candidate after independent rejection of the widened-shoulder refinement.
The smoother compact base remains retained. All earlier source files are untouched.

This changes only the distal upper/sole perimeter. Four existing angular peaks
keep their reach; shallow intervening valleys retract at most 23 mm. Cream peak
height tapers from 39 mm to 13 mm above the same 4 mm sole plane. The existing
orange-boundary ring, complete teal/light dorsal web, shoulder, roots, faces,
colors and skin binding remain exact. No angular retessellation occurs.

The dedicated audit asserts byte-identical protected web position buffers and
identical face ordering and computed face-normal vectors. It also retains all
closed orientation, volume, root containment, exact compact bounds and floor guards.
No static check establishes visual success, self-intersection absence or motion.

Build/check/render use the separate `*_terminal_*` scripts and `terminal-*` mesh
files. Captures compare V71, retained compact base and this terminal candidate at
the same hero/front/side cameras. Review images are stored outside Git binaries.
