# Compact forefin rim refinement

Separate unaccepted candidate following independent review of the retained compact
forefin stance. The prior thirteen files remain unchanged. No runtime changes.

The approved concept has broad pointed cream tips with shallow valleys and an
irregular orange transition, rather than the first compact study's square level
rim. This source reshapes the same continuous fan outline into four broad low
points. Each point tapers in height toward the unchanged sole plane. The orange
boundary gently varies inward across those masses. A broader convex shoulder
carries the unchanged buried root into the fan before the terminal scallops start,
avoiding narrow longitudinal grooves.

`build_refined_fins.py` writes separate `refined-*` indexed/native mesh data.
`check_refined_fins.py` applies the existing topology/root/floor guards and also
asserts that the complete compact candidate's minimum/maximum extents remain exact.
`render_refined_comparison.py` renders V71 and this candidate using the same scene.

The original compact study remains the comparison reference for this refinement;
V71 remains the retained native body and rig. Static passes do not establish
self-intersection absence, skinning quality, or visual superiority. Full matched
hero/front/side comparison and independent review must precede acceptance.
