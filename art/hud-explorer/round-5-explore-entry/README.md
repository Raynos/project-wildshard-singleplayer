# Explore World hub · Practice entry options

[One portrait A–E board](explore-entry-A-E.jpg) compares five ways to enter the shared HUD + Weapon Practice arena **inside the developer-only Explore World hub**. It uses a [live 390×844 Explore hub capture](ref-live-explore.jpg) and the existing Model Explorer, World Explorer, and live Practice arena preview art. The board is a vertical contact sheet meant to be read at phone width.

| Option | Navigation idea |
|---|---|
| A | Three equal one-tap Explorer cards. |
| B | Models, World, Practice mode tabs with one large selected preview. |
| C | Two inspection tiles plus a wide Practice tile. |
| D | Selected mode preview with a persistent three-item bottom dock. |
| E | Swipe carousel with one full mode preview at a time. |

**Review:** Pick A, B, C, D, or E, or request a combination. This board is layout exploration; none of these navigation changes is implemented.

Round 4's title/level-selector placement concepts were superseded by the clarification that Practice belongs only inside developer-only Explore World. Their uncommitted images were removed so they cannot be mistaken for approved direction.
