# grid / round-30-hologram-refs: single-object references for image-to-3D (G542)

Made per ~/ml/img2mesh/refs/gen-refs.sh (plain light-grey background, one object, three-quarter view, ~80% of a
square frame, chunky attached parts). Ember Forge first (the pilot).

The last six (starfall-observatory, mosslight-ruins, alien-plain, desert-ruin, night-market, sky-race) were made with
`scripts/open-plots/gen-refs.sh` (open-plots-mini-plan P3) from their billboards; each was read and holds one object on a
plain background.
