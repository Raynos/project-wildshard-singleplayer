# Grid round 24: the open plot's words and look (G198, SF21a)

**Question:** on the public INFINITE WILDSHARD 3 × 3, the cells without a real shard alternate Template 1 copies and
**open plots** (G198, Jake: *"Half template copies half open plots that say you can build and upload your own shard"*).
There is no upload yet (singleplayer), so the sign has to invite without lying. Which look and which words?

This round follows `art/grid/round-23-open-plots/` (`ef38418f2`), which settled the floor (the VR void) and drew a
staked plot, a holo cube frame and a meadow notice board; its recommended B reads "UPLOAD YOUR SHARD HERE", which
promises an upload that doesn't exist. Round 24 is about honest words, at the plot's entry from the road.

**The layout rule drawn:** walk the ring of eight cells around Driftwood and alternate the empty ones: NW template, NE
plot, SE template, S plot, SW template, W plot (3 + 3). W and S are where dev mode already puts Signal Dunes and Sky
Reach, so open plots are exactly the slots the next shards fill, and the two plots beside Driftwood are the first ones a
new player sees from the pier.

## Recommendation: A, the calm holo sign

- **Honest:** "BUILD YOUR OWN SHARD" is true today (a shard is built with Claude Code and the SDK); it never says
  "upload". B's "THIS PLOT IS YOURS" says the player can build *here*, which they can't; C is honest ("COMING SOON")
  but its billboard reads like an advert and the props say *we* are building something there.
- **Cheap and already built:** it is the refused cell's sign (G167, `art/grid/round-21-refused-cell/a-void.jpg`) with new
  strings, one panel per plot and no per-plot props. B needs four beacons and beams, C a scaffold model.
- **Calm:** the void stays empty, so a plot reads as "nothing here yet" next to an orange Template copy.
- If the SDK isn't public when the grid goes public, swap the second line for **"UPLOADS COMING SOON"**. If far
  visibility matters (the sky-down reveal), add round 23 B's thin cyan cube outline around the plot; the sign stays A.
