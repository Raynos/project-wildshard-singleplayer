# grid / round-27-billboards: new open-plot billboards for the 5x5 outer band (G528)

Ten new billboards in the existing open-plot style (codex `image_gen`, `sky-race.jpg` as the style reference): the Showcase Template, Thin Ice, and Jake's eight picked ideas (Frostline Peaks, Ember Forge,
Lantern Bayou, Sky Harbor, Coral Drift, Clockwork Canyon, Starfall Observatory, Mosslight Ruins). `board.jpg` shows
them with the eight existing images: Jake picks the 14 that fill the outer band's billboard plots.

The four G529 originals (alien-plain, desert-ruin, night-market, sky-race) moved here as JPEG when the game-layer plot
that drew them from `public/assets/grid/open-plot/` was deleted (SF88g P8); these 14 are the sources of
`scripts/open-plots/make-art.sh`.
