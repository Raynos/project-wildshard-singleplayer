# round-40-switchbacks: Sky Reach's four switchback entries, as built (SF49-g)

Ask E435 (SHARD-PLATFORM SF49-g), building Jake's G102 pick (`round-39-entryways/B-switchback-ramp.jpg`): at each edge
midpoint a plank road landing at y = 0 across the platform socket's far edge, a two-lane timber switchback tower and a
plank causeway on trestles straight inward onto the nearest island. Real captures, not mockups: the private build
db70998e9 (HEAD ac4fb4fd7 + commit 462aa01d1's files), the `farReachEntries` Debug row ON, iPhone 16 Pro portrait
(402 × 874 @3×), phone tier, muted, free camera, HUD hidden. Standalone Sky Reach has no road or socket floor yet (the
platform adds them in the grid), so the landings hang over the cloud sea here.
