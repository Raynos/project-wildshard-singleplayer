# Project WildShard

A multiplayer online sandbox game using three.js & typescript. Players can login or enter anonymously to play in a vast open world.

The novel concept of the game, is that the world is chunked, and each chunked is authored by a player, presumably using claude code, the skills, and CLI available as part of project wildshard.

Unlike a game like minecraft where you build inside the game using the gameplay flows, with project wildshard, you use claude code as the UI for building, and it will use the skill/cli/api to upload literally a tarball or zipfile of some threejs code using the provided framework & library from wildshard to build procedural art and zones for each chunk. 

Then players can either build in claude code, or play in the browser.
