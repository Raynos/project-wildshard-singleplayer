# E200

**Status:** in flight (2026-09-26, Codex)
**Ask:** My Dragon Shot appears to have a double loading bar bug. And when I try to load it, it, you know, obviously pulls up the loading bar. But then once it completes, it pulls up the loading bar again. It has to load twice, like there's some kind of bug or glitch here.

Root cause: portrait PWA manifest starts at `/`; the title builds Driftwood, then choosing Nine Dragon builds a second world with a second loader. `ShardHost.timings` on the live build confirmed `first: driftwood-isle` followed by `build: nine-dragon-stack` without a page navigation. The screenshot's Download and Setup bars are separate progress measures within one build.

Change: persist the last successfully selected shard and use it for the PWA root launch when no explicit harness `chunk` is supplied. The GPU texture-mode resolver uses the same saved slug. A local portrait root launch with Nine Dragon saved produced exactly one `first: nine-dragon-stack` timing. TypeScript, chunk tests, CSS check, and build passed. A first-ever launch with no saved selection still loads the default world before a different choice; eliminating that first selection build requires a title shell that does not boot a world.
