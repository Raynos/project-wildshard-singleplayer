# E337

**Status:** done (2026-09-30): fixed `7139c2cb`, live `d1cdcee-munun0hj`. Jake confirms on his desktop Chrome.
**Ask:** Black screen area on desktop in Nine Dragon: the sky behind the paifang and between the towers renders black (Chrome desktop, wildshard-singleplayer.vercel.app/?chunk=nine-dragon-stack)


## Fix (2026-09-30, the render lane)

- **Cause:** pass 5's far skyline squared a signed value with `pow(x, 2.0)`. In GLSL, pow() of a negative base is
  undefined. Apple GPUs return x², but D3D through ANGLE (Chrome on Windows) computes exp2(y·log2 x) = NaN. So every
  sky pixel below a skyline layer's base went NaN, and the composite clamped it to black.
- **Fix:** square by hand. The same pattern in the desktop reflection pass (the drizzle rings) is fixed too. The sky's
  depth sits at 0.99999 w, so a driver whose z/w rounds over 1.0 cannot fail its depth test.
- **Proof:** emulating D3D's pow on the sky program reproduces the bug on the old HEAD. Desktop and phone are
  pixel-identical on this Mac at the four mockup cameras, before and after:
  `art/nine-dragon-stack/round-24-mockup-pass/render/e337/`.
