## Answer (2026-09-29): yes, every step has a touch control; three traps

`scripts/nalati-quest-check.mjs --touch --only=chapters`: 14/14 (flag-driven chain; a run of the full script failed on
`__nalatiQuest` after the section reload, a script timing issue). A code audit of every step's input on the phone HUD
(3 agents) found no keyboard-only step. Traps:

1. Taming: a full MOVE-stick push (> 0.85) is a touch sprint, which silently stands you up (stealth.ts crouchStep).
   Standing within 30 m of the stallion: ALERT +10/s, TRUST gain 0, he rears / charges / leads the herd away.
2. Wind Cairn: the tie prompt only shows mounted, but the horse's own Dismount prompt (hidden on touch) is nearer, so
   the USE band stays empty until you are within ~2 m of the tie spot (3.6 m on the cairn's +x side).
3. Qara Batyr only spawns after 5 ghost riders are killed that night; nothing in the game says so (the feathers are
   optional: any three, or beat Jel Ata).

Waits (all platforms): dusk ~3.3 min after a load (balbals up ~10.5 min, next dusk every 26 min); the first storm
~16.5 min after a load, then every 28–39 min. Minor: the spear's BRACE replaces JUMP on touch (Golden King's sunburst);
the carving box overlaps the top of the JUMP / DODGE row.
