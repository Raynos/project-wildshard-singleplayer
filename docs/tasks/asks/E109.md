# E109

**Status:** done (2026-09-24)

**Cause:** index.html cancels every `touchmove` outside a `[data-scroll]` element (so the page never rubber-bands). The Explore catalog grid, its filter chips and the creature variant row were never marked, so a finger drag was swallowed.
**Fix:** `src/explore/ModelExplorer.ts` marks `.ws-x-grid`, `.ws-x-filter`, `.ws-x-variants` with `data-scroll`; `src/ui/styles/explore.css` gives them `touch-action: pan-y|pan-x` and `overscroll-behavior: contain`.
**Evidence:** a CDP touch swipe on iPhone 13 emulation: live build scrollTop 0 → 0 (of 333 px); the fix 0 → 262. `progress/221-e109-explore-grid-swipe-before-after.jpg`.
