The loader now shows load attempt, Chromium JS heap when exposed, an estimated scene-texture allocation after first frame, and the longest page-thread pause. The linked fps-detector and stats.ts tools use Chrome's `performance.memory`, so switching to Chrome on iOS does not make that API available to a Safari-installed PWA.

Sources: [MDN `performance.memory`](https://developer.mozilla.org/en-US/docs/Web/API/Performance/memory), [WebKit Web Inspector Memory and CPU timelines](https://webkit.org/web-inspector/timelines-tab/), [Chrome for Developers: iOS uses WebKit](https://developer.chrome.com/docs/web-platform/blink).
