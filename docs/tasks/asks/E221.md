## Verification and limits

- `jq empty .codex/hooks.json` succeeds; both symlink targets resolve to `SKILL.md`.
- Sample Codex `PreToolUse` JSON blocks `git add -A` and bare `git push` with exit 2; safe commands pass. The hooks use repository-root paths so a session launched in a subdirectory finds them.
- `node ~/projects/dotfiles/agent-common/sync-agent-tooling.mjs check` reports the four shared CLI/MCP capabilities present for Claude and Codex: agent-browser, Context7, Playwright, and Chrome DevTools. Codex's browser plugin is also declared in the inventory.
- Codex requires a one-time `/hooks` review of this new project hook definition before it will run; this task does not write its trust record. Standalone skills work in the ChatGPT desktop app; ordinary Chat does not run local project hooks. The command scripts must be available on the machine that runs Codex.
- Dotfiles already has unrelated uncommitted edits to `codex/hooks.json` and `claude/settings.managed.json`; this task leaves them untouched. A separate dotfiles follow-up can add personal `handoff` skill parity and reconcile the duplicate Herdr SessionStart entry without sweeping that WIP.
