## The fix

`src/explore/ModelExplorer.ts` + `src/ui/styles/explore.css`: a **‹ / ›** pair in the card's head row, right-aligned
next to the model's name.

- `shown()` is the list the catalog is showing (`entries` under the current category filter, in the grid's own order);
  `step(-1 | 1)` opens its neighbour, wrapping round at each end.
- The pair hides when there is nowhere to step — a lineup, or a filter with one model left.
- The file path moved to its own line under the name, so the buttons keep the head row's right edge.

Verified on an iPhone viewport: PIER → **›** → SAILBOAT → **‹** → PIER.
