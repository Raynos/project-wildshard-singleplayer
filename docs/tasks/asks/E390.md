**Status:** done (2026-10-02, lead): weatherFog in #engine; ships with the next deploy
**Ask:** [from signal-dunes] ENGINE REQUEST: a shard-settable fog density for weather (the Matriarch's sand storm): the engine fog is exponential and ignores scene.fog near/far, so the storm can't close the fog.


**API:** set `atmosphere.weather: true` in the manifest (it compiles the term into this level only), then `const storm = weatherFog(ctx.scope, { dist, height?, color }); storm.set(strength)` (0..1) whenever you ease it; cleared when the scope ends. It is a second exponential fog over the level's own (density per metre), so it composes with a backdrop clock and the underwater blend. ENGINE.md: the look table's Fog row. Test: test/engine/weather-fog.test.ts.
