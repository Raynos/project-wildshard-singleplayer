# E180

**Status:** done (2026-09-25) — commit below; build id under it.
**Ask:** Inside the model explorer, we need to either move the card up because the corners cut, or make it have rounded corners.


## The fix

`src/ui/styles/explore.css`, `.ws-x-sheet` (the turntable's model card):

- **rounded**, the bottom more than the top and more again on a touch screen (`--ws-x-rb: 12px` → `26px` under
  `@media (pointer: coarse)`), which is the pause sheet's trick from E139. The cyan corner brackets bend with the radius
  instead of poking out of it.
- **lifted**: `bottom` is now `calc(max(16px, env(safe-area-inset-bottom, 0px)) + var(--ws-home, 0px))`. `--ws-home`
  (src/core/viewport.ts) is 34 px in the home-screen PWA on a Face ID phone and 0 elsewhere — the stand-in for the home
  indicator that WebKit reports as a 0 inset because index.html has no `viewport-fit=cover` (E58).

Measured on a 402x874 standalone viewport: the card's bottom sits **50 px** off the screen edge, radius
`12px 12px 26px 26px`. Both, not either — the radius alone still left it on the home-swipe strip.
