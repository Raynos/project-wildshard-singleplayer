  bytes, over everything (z-index 2147483000), shown by `@media (orientation: landscape) and (pointer: coarse) and

  portrait phone squashed by its soft keyboard from counting as landscape.

  `rotateGated()` to the frame gate, so the world neither ticks nor renders behind the page.
- PWA manifest `orientation: portrait`; iOS `UISupportedInterfaceOrientations` = Portrait, Android `screenOrientation="portrait"`
  (docs/plans/NATIVE-APPS.md N4 updated; the shells need a `cap sync` + rebuild to pick it up).
