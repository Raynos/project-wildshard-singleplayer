# E184

**Status:** done (2026-09-25) — `f9383ce4`, live as `f9383ce-muhvkokg`.
**Ask:** WebGPU setting is completely borked. Delete all the WebGPU code and the experimental renderers so there is only WebGL, and remove the Renderer picker too.


## What went

**`src/gpu/` is deleted** — all 13 files, 1523 lines: `flag.ts`, `GpuPath.ts`, `bridge.ts`, `compat.ts`, `ports.ts`,
`materials.ts`, `effects.ts`, `post.ts`, `sky.ts`, `ocean.ts`, `fog.ts`, `toon.ts`. That folder *was* the whole
experimental path (its own doc: "Anything else, or no flag, is the shipping WebGLRenderer + pmndrs postprocessing
path, unchanged"), so nothing shared had to be untangled — the WebGL path is untouched.

With it:

- **`src/core/Game.ts`** — the `GPU_MODE` branch. The renderer is built on the real canvas again (WebGPU mode used to
  hand `WebGLRenderer` a throwaway offscreen canvas), and `game.gpu`, `gpuReady` and the six `if (this.gpu)` forks in
  `buildSky` / `buildComposer` / `precompile` / `firstFrame` / `resize` / the frame loop are gone.
- **`src/ui/Settings.ts`** — the `gpu` option (and so `?gpu=`), plus `gpuShadows` and `gpuToon`, which existed only to
  A/B the two paths. `BOOT_OPTIONS` is `['tier', 'touch']`.
- **`src/ui/BootSettings.ts`** — the **Renderer** picker and its EXPERIMENTAL chip. "Running now" reads just the
  quality tier. The Debug card E177 added here now holds the Developer switch alone.
- **`src/ui/debugOptions.ts`** — the two `WebGPU shadows` / `WebGPU toon` rows.
- **`src/pwa/sw.js`** — `OPT_IN = '/assets/GpuPath-'`, the rule that kept ~240 kB gz of `three/webgpu` out of the
  precache. There is no such chunk any more. (`/assets/gpu/` is the **KTX2 texture store**, a different thing, untouched.)
- **`lint/url-params.json`** — `gpu` off the harness allowlist.
- `test/settings.test.ts` — the four cases that used `gpu` as their example key now use `tier` / `time`.
- Stale comments in `GpuRecovery.ts`, `Sky.ts` (`GPU_MODE === null` in the Pine Hollow clock gate),
  `shadowChunks.ts`, `PineDayNight.ts`, `pinehollow/weather.ts`.
- The open WebGPU rows in four live plans are marked **dropped (E184)**: DRIFTWOOD-REMASTER-V2 V-G1 / V-G2,
  PINE-HOLLOW-FOLLOWUPS F-P5, FINISH-LINE S4 (now done), GAME-NORMALIZATION's non-goal.
