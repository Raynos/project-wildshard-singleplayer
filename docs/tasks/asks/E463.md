# E463

**Status:** done (2026-10-08) — live in production build `9ee6df47` (22:13 UTC)
**Ask:** When I enter driftwood I spawn under the bridge. This is in the infinite wildshard


**Cause:** Driftwood's manifest spawn `(0, -194)` had no height, so the grid's owned home placed the traveller at the terrain
height under the pier (the seabed) instead of on the G164-lowered deck, whose colliders aren't in the frame physics yet when the
home spawn is placed. **Fix:** `ebf0b79c3` (the manifest spawn carries the deck's y = 1.2, as `shard.config.ts`), `c6daff06e`
(spawns without a height stand on the highest surface: terrain / water / platforms / a deck within 2 m, used by region respawn),
`8e5dc65d3` (fixture). **Test:** the boot smoke's grid case now casts up from just above the settled player's capsule in the live
physics and fails when a collider is within 3 m (it caught the deck 1.055 m over the old build's -0.845 m feet; the fixed build
stands at y 1.204). The black grid minimap in the report came from production `29e6895`, before the stylized baked maps (`edad5463d`);
current main draws Driftwood's map inside its cell.
