**The registry.** `src/ui/debugOptions.ts` declares every Debug toggle once: `opt(key, group, label, choices, { reload,
when, note })` over a `Settings.ts` option (`OPTION_SPECS` → `DEBUG_ONLY`), or `action(...)` for a button row.
`src/ui/DebugMenu.ts` renders pause ▸ Settings ▸ Debug from it: a filter box, then one collapsible group per domain
(collapsed by default, open state in `ws.debug.open`, the header counts the rows that apply here, a group with none
here is hidden). Groups: Look · Ground cover & foliage · Sky & weather · Audio · Combat & weapons · Creatures & NPCs ·
Performance · Loading & memory · Developer tools. `test/debug-options.test.ts` fails an option with no row or a group
with no row. Scripts set options before load with `scripts/debug-settings.mjs`. AGENTS.md "No URL switches" says how.
