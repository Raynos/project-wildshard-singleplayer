**Ask:** How do you auto resume from the 5hr limit in claude code CLI ?

Claude Code v2.1.234 added automatic continuation when a claude.ai usage limit resets. It is enabled by default; `/config` → "Continue automatically at usage limit" controls it. Local `claude --version`: 2.1.283. Keep the CLI session running until the reset. Release evidence: https://github.com/anthropics/claude-code/releases/tag/v2.1.234
