## Verdict (Claude, 2026-11-04)

No earlier request was found: the repo, the asks and every Claude transcript only match "Claude memory".

claude-mem (github.com/thedotmack/claude-mem, Apache-2.0, v15.9) hooks six Claude Code events, including
PostToolUse. A local Bun worker compresses each tool observation with an LLM into SQLite + Chroma, then injects past
observations at session start. The LLM is the hosted observer (a trial, then your Anthropic plan), OpenRouter or
Gemini.

It would not have helped over 10-07 → 11-04, because:

- **Volume**: 18,128 commits from about 10 concurrent agents, 1,119 Claude transcripts with 350,929 tool calls, and
  758 Codex sessions. An LLM compression call per observation spends the plan quota that G960/G1007 already
  ration across the Opus lanes.
- **Memory poisoning was the real failure**: on 11-04, stale MEMORY.md lines drove about 48 wasted mirror checks.
  Auto-captured, unreviewed memory makes this worse. E423 deliberately moved rules into AGENTS.md / docs/process,
  where Codex and Claude both read them.
- **The memory we need already exists and is shared**: STATE.md per plan, commit bodies (`git log --grep`), asks,
  and the transcripts (`rg` over ~/.claude/projects and ~/.codex/sessions).
- **G585 / G506**: a new daemon, hooks on every tool call and a vector DB on the shared Mac are exactly the new
  machinery those rulings forbid. Concurrent-session behaviour is undocumented, and orphaned workers have been
  reported.
