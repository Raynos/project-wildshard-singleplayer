**Ask:** [from sky-reach] ENGINE REQUEST: let a level hand the god-ray pass its own light source (Sky Reach hides the engine sun disc because its panorama paints the sun, so it gets no god rays)

**API:** `sky: { …, sun: { disc: false, rays: true | { azimuth, elevation } } }` keeps the disc as the god rays' source
only (out of the scene, so never drawn in the frame; GodRaysEffect draws it in its own light scene). `{ azimuth,
elevation }` uses the `sky.sun` compass; `sky.raysDir` is the direction (the sun's by default). ENGINE.md: the sky
dressing sun section. Files: src/engine/render/look.ts, src/engine/world/skyBackdrop.ts, src/engine/world/skyRig.ts,
src/engine/core/Game.ts.
