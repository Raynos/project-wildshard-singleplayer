# E260

**Status:** done (2026-09-28, explanation; watchdog implementation tracked in E261)
**Ask:** 4.5Gb sounds like the answer: how do we get memory usage without USB in iOS Safari or Chrome, limit the iOS Simulator to 4GB, or get RAM usage from the Mac inspector?


Safari on the connected phone exposes neither `performance.memory` nor `measureUserAgentSpecificMemory` (both checked through its inspector). Native process RAM cannot be uploaded automatically by ordinary page JavaScript or Sentry. App-owned texture/geometry/decoded-audio byte accounting can provide explicitly labeled estimates and durable checkpoints.

Safari supports wireless Web Inspector after initial pairing; Timelines → Memory records page memory and JS Allocations helps identify retained objects. A Simulator has no supported 4 GB RAM cap in the installed tools; a native external watchdog can instead fail a test at a measured footprint threshold (E261). Simulator results do not substitute for physical iOS Jetsam thresholds.

References: https://developer.apple.com/documentation/safari-developer-tools/inspecting-ios ; https://webkit.org/web-inspector/timelines-tab/ ; https://developer.apple.com/documentation/xcode/identifying-high-memory-use-with-jetsam-event-reports .
