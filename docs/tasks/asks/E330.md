## Findings

The post introduces UniMate, a unified text-to-motion model for diverse already-rigged
characters. Primary sources verified on 2026-09-30:

- Project: https://linzhanmou.com/unimate/
- Code: https://github.com/Friedrich-M/UniMate
- Released models: https://huggingface.co/Linzhan/UniMate

The model supports text-conditioned motion, pinned-frame transitions, pinned-joint
editing and chained motion expansion; the export pipeline writes animated GLB/FBX.
The current recommended v2 denoiser has 74.1M parameters, supports 5–70 joints and
generates 60 frames at 30 fps per sample. Code and checkpoint model card report MIT.

Important practical details: a new custom rig must be preprocessed into a feature
directory and currently needs at least one existing animation clip. This does not
automatically rig the static meshes produced by our TRELLIS/Hunyuan workflow.
The environment pins CUDA PyTorch wheels; local MPS compatibility and speed have
not been tested. No model downloaded, installed or run in this assessment.

Assessment: potentially a substantial improvement in creature/NPC animation authoring.
Generate clips offline and play normal skeletal animations in Three.js. Suggested
first evaluation: one of our rigged horses, three motions (idle, walk, rear), checking
deformation, hoof sliding, transitions, GLB playback and phone cost before wider use.
