# E182

**Status:** done (2026-09-25) — `bc7153f1`, live as `1495d72-muhvgeut`.
**Ask:** The X button on the model explorer kicks you back out to level select


## What it was

`.ws-x-close` was wired straight to `Explore.close()`, which leaves Explore for the title — from anywhere, including a
turntable three levels in. Esc already did the sensible thing (one step back), so the two disagreed.

## The fix

`src/explore/Explore.ts`: a `back()` that takes **one step**, and both ✕ and Esc run it.

    an open overlay (Compare, the map) closes
    → else the pane takes its own step (`ExplorePane.back?()` — the Model Explorer's turntable goes to its catalog)
    → else a mode goes back to the hub
    → and only from the hub does it leave Explore.

The button says which step it is: **‹** while there is somewhere inside Explore to go back to, **✕** (and
"Back to the title") when the next press leaves. `src/explore/ModelExplorer.ts` implements `back()`.

Verified: ✕ on a turntable → the catalog; again → the hub, where the glyph turns back into ✕; again → the title.
