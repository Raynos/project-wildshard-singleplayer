Queueing on its own is cheap: the waiting costs nothing. The money goes on waking up after a >5-min wait with an expired
cache (75 % of the $467). The fix already landed: long waits belong to the main agent. The slowdown contention causes
inside captures (a busy CPU / GPU makes a run take longer) isn't measured here.
