## Landed (2026-09-30)

- AGENTS.md "Subagents are short-lived": the main agent builds by default; ≤3 live subagents per main session; one job,
  ≤250k context, ≤45 min; never recycled; no forks; long waits go to the main agent (`run_in_background` + notification,
  1 h cache) instead of 4-min polling. drain-inbox skill follows it.
- `.claude/hooks/guard-subagents.sh` (PreToolUse `Agent|Task`) enforces the cap / no forks / no nesting; tested on a fake
  session (3 spawns allowed, 4th blocked, frees on `end_turn`) and on be65981d (correctly saw its 3 live lanes). Takes
  effect on a session restart.
- Hourly usage log: dotfiles `claude/usage-log.sh` (64db2cd, 21ae18f), cron `17 * * * *` → `~/.claude/usage-log/<ISO
  week>.jsonl` with the active login email + every OpenUsage Claude account. README.md "Claude plan usage".

## Follow-up: were the long-lived subagents mostly waiting on browsers? (2026-09-30)

41 subagents ran >1 h in the last 16 h: 141 agent-hours, $1,763.
- **Time: about half was waiting.** 63 h (45 %) blocked in tools. Browser work was about 35 h of that: captures,
  benches and walks (11 h), the lane queue (2 h) and `until grep … tasks/<id>.output` loops polling a background browser
  job (~22 h). The rest: the model lock ~5 h, git / CI ~6 h, unknown ~13 h. 120 of 844 poll loops ran into the 10-min Bash
  timeout and were simply re-issued.
- **Tokens: about 40 % went on waking up cold.** Waiting costs nothing. The cost is the next call after a >5-min wait,
  which re-writes the whole context: ~$700 (40 %) of the $1,763, ~$400 of it after browser / capture waits. Calls after
  a poll loop or browser run cost ~$880 in total (50 %). The other half was real work (bash, git, builds, edits,
  images) at 400–900k context.
