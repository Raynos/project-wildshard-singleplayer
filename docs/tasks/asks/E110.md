# E110

**Status:** done (2026-09-24)

**Cause:** shadow acne. The sail is a zero-thickness, two-sided, swaying cloth in the same mesh as the hull, which both casts and receives shadows, so it shadowed itself triangle by triangle.
**Fix:** `src/world/Boat.ts`: the sail is its own mesh (`boat.sail`), castShadow on (with the sway depth material), receiveShadow off. +1 draw call.
**Evidence:** `progress/220-e110-sail-acne-before-after.jpg` (same camera, live vs fix). The hull still shows the same acne: that goes with the boat remake, E113.
