- Jev: TypeSafe, hosted, text only. Clef / Clef-flash: Cloudflare, Apache-2.0, with vision; claims Jev-API compatibility.
- Audit findings:
  - Confidence semantics differ between the two (Jev uses the spread of the probabilities, Clef's reference code uses
    the max probability), so thresholds don't port.
  - Clef scores questions jointly, Jev in isolation.
  - The reference code silently cuts the tail of the state at 16k tokens.
  - The GGUF quants have no joint head, so they don't run Clef.
  - On real coding-agent decisions, accuracy is about 70 %.
- 4-bit: `mlx-community/clef-flash-4bit`, 6.2 GB with vision, measured on an M5 Max at a 311 ms median, the same top
  answer as bf16 on 96.4 %.
- Fit in this repo, ranked: capture QA (~5.7k image Reads in the transcripts) → the WorldClaw T12 style-check first
  pass → session-brief ask status → inbox triage → model self-review. The Bash guard hooks stay regexes.
