# E402

**Status:** done (2026-10-03, lead): ships with the next deploy
**Ask:** [from sky-reach] ENGINE REQUEST (low priority): a look compose that reads c.fx before c.engineChain('clean') makes the clean ask throw and the load hangs silently (480 s in the capture); surface it or don't let fx pick a chain implicitly

**Cause:** the compose context's `get fx()` builds the `'cinematic'` chain when nothing is built yet, so a later
`c.engineChain('clean')` throws. The session does catch it and shows the error modal; the "hang" was the capture
harness waiting 480 s for the load screen to go.

**Fix:**
- `src/engine/app/app.ts`: the app state is mirrored on `<html data-ws-state>`, so a harness can stop on `'error'`.
- `scripts/shard-progress.mjs`: stops at once with the error text when the state is `'error'`.
- `src/engine/core/Game.ts`: the error now names its cause (read `c.fx` after `c.engineChain()`).
- `docs/ENGINE.md` (the ExtendLook row): ask `c.engineChain(kind)` before reading `c.fx`.
