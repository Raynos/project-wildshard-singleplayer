# E177

**Status:** done (2026-09-26) — `105c090b` (live `bcf12c4-muhuqijs`); follow-up `26f8b96a` (Developer switch back in the open), live as `52f4967-muhy9dzk`.
**Ask:** The debug cards in main menu & pause menu should be collapsed by default and opt into expansion.


## What it was

The pause menu ▸ Settings Debug card was **1166 px of the panel's 2215 px** scroll height on a phone — over half the
screen's worth of variant pickers (music style, SFX set, time of day, frame cap, six ground-cover rows, textures,
prefetch, shard cap) above nothing a player wants. The main menu ▸ Settings had no card, but the same clutter loose in
the panel: **Experimental ▸ Renderer** and **Developer ▸ Developer mode**.

## The fix

- **`src/ui/cards.ts`** (new) — `foldCard(id, title, sub)`: a `ws-gmenu-card debug fold` whose title bar is the toggle.
  **Folded by default**; the choice is remembered per card in `localStorage` (`ws.fold.<id>`), so a debug session that
  opens it keeps it open, and a storage-blocked browser just reads as folded.
- **`src/ui/styles/gmenu.css`** — `.fold` / `.folded` / `.ws-gmenu-foldmark`: the title becomes a full-width button with
  a caret that turns down when it is open; folded, every child but the title is `display: none`.
- **`src/ui/Menu.ts`** — the pause menu's Debug card is a `foldCard`. Its memory readout stops ticking while folded.
- **`src/ui/BootSettings.ts`** — **interpretation, tell me if it is wrong:** the main menu has no card called Debug, so
  its counterpart is the Experimental renderer + the Developer switch; they moved into the same folding **DEBUG** card,
  under Controls.

Measured on an iPhone 16 Pro viewport: pause ▸ Settings scroll height **2215 → 1116 px** (2223 when Debug is expanded);
main menu ▸ Settings **fits on one screen** with nothing to scroll.

## Follow-up (2026-09-26, Jake's pick: "Back in the open")

Main menu ▸ Settings: the **Developer mode** switch is back in the open, under Controls, for everyone. The folding Debug
card now holds only E172's Debug registry and, like the pause menu's, **shows only in developer mode** — a player sees no
empty card. Checked on an iPhone viewport: dev off → no card; dev on → the card, folded; the switch is outside it both ways.
