# E218

**Status:** in flight (2026-09-26, Codex)
**Ask:** The Nine Dragon loading screen freezes in Props, caching appears not to work, then Safari iOS kills the PWA. Show useful memory or loading diagnostics if browser APIs permit; research Safari/iOS memory limits and fix the crash.

WebKit engineers describe an approximate 1.5 GB soft WebContent process limit on most iPhones, lower on smaller-memory models and dependent on other processes' pressure. Safari does not expose a reliable total process footprint to page JavaScript. Apple Web Inspector on a connected Mac can inspect the Home Screen web app's Memory timeline. The app-side phone proxy uses WebGL allocation tracing and collected JS heap; E217 records the before/after.
