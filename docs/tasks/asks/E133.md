The session brief counts new ones.

- 5de4ef9 `api/errors.ts` is self-contained. Importing `./inbox` broke the Vercel function.
- 96aa76e a fatal fault marks the loop dead before the modal hears it, so the modal no longer offers KEEP PLAYING on a stopped loop.
