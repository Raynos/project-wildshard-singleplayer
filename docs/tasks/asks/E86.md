# E86

**Status:** in flight (2026-09-23, main session)
**Ask:** Pause => edit to main menu didn't work it just froze the game


Cause: pause → Exit to main menu re-shows the title with the ENTER WORLD callback the title screen stored. A session that
skipped the title (a GPU-recovery / app-switch reload `?glreload`, E61; `?skipintro`) never stored one, so the exit
cleared `entered` (the frame gate stops the world) and showed nothing: a frozen frame. Fix: `hud.markEntered(enter)`
stores it on those paths too. Headless check (Playwright, pause → Exit → ENTER WORLD) on normal / glreload / skipintro:
live build before the fix: title missing on glreload + skipintro; with the fix: the title comes back and ENTER WORLD
re-enters on all three.
