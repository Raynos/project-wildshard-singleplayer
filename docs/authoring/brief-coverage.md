# Mandatory Mesa Outpost coverage

The retained author-template runner `prove-mesa.ts` exports `proveMesaOutpost(shard, assets, page, plan)`.
It imports only public SDK and commons modules. Supply the built product's admitted bytes and a Playwright page
already entered in that product. The plan names exactly three distinct goat spawns, one hawk, the beacon interaction,
its script-owned boolean state field, and a finite native input route (0–4096 ticks) to reach it.
The route uses ordinary commands, never a supplied snapshot or teleport. The beacon must remain unlit through
the approach; the runner then requests the real interaction itself. All checks run; there are no optional requirement switches.

The SDK owns an isolated native worker. Each goat must actually enter flight, travel over 10 m and finish over 15 m
from the player. The hawk must dive to within 1.21 m above the player, record a landed strike in its native policy
continuation and reduce actual player health. A declared creature, animation or idle policy cannot pass. The beacon
must start unlit and become lit through the nearest reachable scene interaction, with actual native LOS. A control replay from the same checkpoint must remain unlit without interaction. A numeric
script event, timer-only light or pre-lit state cannot substitute for this interaction. A checkpoint's next 30 native ticks must restore
byte-exactly. The report records observed displacement, distances, health, strike receipt and checkpoint tick.

The runner checks the exact `starter-spear` commons catalogue closure and primary loadout: immutable model bytes,
contact/profile bytes, charged commons requirements and library entries. In the normal built client it requires the
current weapon to be mounted on the actual viewmodel, visible, and drawing nonempty geometry from that admitted
asset lease. An unequipped declaration or replacement placeholder fails. It also runs `proveSceneClient` for every
required live native-bound creature skin and the page's selected beacon prompt. Use a real in-game viewing pose;
the runner never moves the player or substitutes a view.

Call this runner alongside `wildshard validate` and `wildshard prove`; those still own entry walking, budgets,
grid continuation, quest facts and Ledger filing. This is functional brief coverage, not the Opus readability or
looks grade. A successful report cannot claim those separate grades.

and the generated commons spear. It does not implement the full mesa art or dusk quest. The test
`scripts/test-author-brief.mjs <built-client-directory>` builds that fixture with the retained authored floor and
runs every mandatory coverage check against the actual native worker and a muted portrait client. Run it through
`scripts/browser-lane.sh` and respect `.git/quiet`.
