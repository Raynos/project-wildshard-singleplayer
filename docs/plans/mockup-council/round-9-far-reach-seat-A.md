- **D `roc-opening`: live, but not verified as the claimed ordinary opening.** Source adds the same 1.5 s/2.5 m/s/4 m take-off branch to normal combat, so this is more than the old arbitrary lap placement. However, normal first-fight `begin` only sets phase/fighting; `think` sets the take-off timer. The brain's angle starts at 0. `stageOpening` additionally cancels attacks, resets rest to 2, forces circle, sets angle from the north perch (approximately −π/2), and snaps position/yaw to that perch. Normal begin/reset does not perform that initializer. Thus a fresh normal fight pursues a different circle target, while retries can retain previous angle/rest. The assertion “this opening at every fight's start” is false as implemented. A matching unstaged position/yaw/bank/state trace from this approach is missing. This is a concrete staging-equivalence finding, not proof that every possible matching frame is unreachable.
- **Pose/effects:** D is active with `calm=false` and uses advancing flight/wing animation. There is no new frozen pose. Its stage requests the normal storm strike at 1 s; the capture is at 0.5 s, so that request alone does not prove a fresh dynamic bolt in the screenshot. No effect-suppression change was found.
