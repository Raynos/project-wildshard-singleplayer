## 2. The battery

5. **Pine Hollow onto the grid** — partial. SF47 says what it must become (`gpuTrace` first, library ≤ 25 MB, tiles in caps, ordered by MB saved), but not when: it sits inside an L-sized 80/20 row with no grid-ready split, off M2's stated path (R2-C5).
6. **MMO server team** — pass. It relies on `@wildshard/engine/sim`, format v0 with host-owned state, same-engine replay and the ledger; it would find whole-sim cross-engine identity absent (G48, by design), `runtime/` shards marked transitional, and the template's multi-instance placement singleplayer-only (R2-C14).
7. **Modes and toggles** — fail. Signal Dunes in dev mode: specified. Nine Dragon: no cell, toggle location unnamed, and still reachable in the shipped game through Select a shard "unchanged". Explore mode: two homes (R2-C7).
8. **A look under one frame** — pass. SF10a painterly family, SF19b keeps the old look as a Debug variant and sends a board; the default while Jake's pick is pending, and on which path, should be said (R2-C16).
9. **Hostile script** — pass. SF11a refuses unmetered modules before running them; SF11b freezes the entity, rolls back to the last good snapshot, rejects NaN, shows a dev-only toast; SF14 makes a replayed fact grant once.
10. **API bump in alpha** — pass with a gap. §3.4 loads N and N−1; first-party shardfiles rebuild every build; an outside author sees a "needs upgrade" card and upgrades by hand, since `wildshard upgrade` is S18.
