# Plan: Driftwood slop sweep (E318)

**State:** `draft` 2026-09-29 — the sweep list; Jake approved none yet.

## Read this first

Jake, 2026-09-29: "I'm leaning towards cleaning, simplifying, lean, as little feature bloat / feature slop as possible …
too much placeholder shit floating around. The more we can delete and simplify, the better." He asked for every
placeholder, dead or half-built thing still in Driftwood Isle, each with a one-line verdict, so he can cut them in one
pass.

- **How it was found:** a read of the shard's code (chunk, quest, interactables, `main.ts`, `src/ui/*`), the E108 and
  phone audits, the Driftwood plans, and the live build `412d443-mun9x88v` played headless as an iPhone 16 Pro in
  portrait (touch, phone tier, muted). Nothing in the game was changed.
- **Board:** [`art/driftwood-audit/round-4-slop-sweep/board.jpg`](../../art/driftwood-audit/round-4-slop-sweep/board.jpg).
  Its cards carry this table's row numbers, so "delete 1, 2, 5–9" means these rows.
- **Order:** rows are ranked by how early and how hard a first-time player meets the thing. Dev-only and code-only rows
  come last.
- **Pure** in the Verdict column means a deletion with no taste call: nothing the quest needs, nothing Jake picked. The
  other rows need his yes.
- **The loot rows** (harvest, junk, doubloons, sea glass) are being redesigned in
  [DRIFTWOOD-LOOT](DRIFTWOOD-LOOT.md). They are listed here, marked "see DRIFTWOOD-LOOT", and decided there.
- **When Jake picks:** each picked row is cut in one commit (row, code and any toggle together), per the AGENTS.md rule
  "when Jake picks a winner, delete the row".
