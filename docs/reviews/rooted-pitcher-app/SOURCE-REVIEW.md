# Rooted Pitcher isolated app source review

21 October 2026. Engineering candidate only; no app/browser run, shared Arena
admission, visual score or phone-performance claim in this source milestone.

## Reviewed scope and design

The real retained v3/core-runtime-study pack has seven native bones and seven
exact source hulls. This is not the later grown-anatomy render or synthetic
geometry. The two-strike source retains central crown and bilateral side-head
attacks; all three heads participate. The separate anchored-held death holds the
actual lethal pose on one fixed compound, with no throw, folding or droop claim.
Default rigid behavior and resource limits remain unchanged. Original rejected
thrown studies are retained and are not relabeled as passing.

Independent source review found the fixed compound, current-transform overlap
preflight, atomic allocation boundary, retained reservation, player obstruction,
loot and disposal contracts sound. Its independent 80-test rerun passed but it
correctly identified that a generic overlap exception could disable a live game
system. The correction uses a narrowly typed DamageRefusalError only for expected
finite pre-allocation overlap, caught around ordinary applyDamage only. No false
damage/death receipt is emitted. Allocation, cleanup, nonfinite data and terminal
fall errors are not swallowed. Separate author regressions passed 53 cases;
root's final combined regression passed 107 tests across eight explicit files.
These include actual pipeline retries through the fault-accounting boundary,
not a browser instance or a substitute for the upcoming real fight.

The isolated app uses the ordinary Game, TrainingArena, PracticeCreature,
PracticeNativeActor and shared native corpse owner. Start creates one canvas/world;
Back disposes it, Retry uses the existing bout reset, reload is real navigation.
Null persistent storage and empty save namespace preserve world/quest isolation.
The current public shared Arena and its four fallback hosts remain untouched.

## Build and capture corrections

- The product author now invokes the existing strict SDK admission mode with the
  exact prepared decision-script rows before emission/re-read. SDK warn defaults
  were not changed globally.
- Pre-enforced generated-table replacement and exact actual entry/boot assertions
  prevent the earlier ordinary-resolution/synthetic-entry mixup.
- The root pin binds the exact source commit/tree, complete source inventory,
  dependency locks, node version, canonical pack, review and build/QA scripts.
  It refuses implicit environment files and changed inputs before/after execution.
- Observer provenance is explicit for this actual-source candidate, while old
  synthetic callers retain their default. Observation never advances poses,
  clocks, physics or damage. A labelled DOM overlay displays the sampled real
  draw/native-clock values only after the original draw call.
- Recorder frames may repeat or omit draws. ffprobe frame count/cadence/duration,
  portrait dimensions and content hashes are receipts, not application or phone
  cadence. Exact trace/video correlation requires matching the visible overlay;
  wall-time anchors remain approximate.
- Back disposal is saved after the click before a new observer replaces it.
  Back-start faults/errors/overflow affect the verdict, as do cycle and reload
  evidence. Original traces, failed captures and complete videos are retained.
- QA uses actual movement/attack inputs; diagnostic player placement is logged.
  It must not force enemy health, pose, clocks, kills or a passing outcome.
