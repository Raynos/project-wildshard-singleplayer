# Conch native likeness: separate transport from presentation

2026-10-20. Read-only diagnosis plus this report only. No build, render, source edit, Git write, admission, publication, Mac operation or new dependency. Current ownership/motion integration files were not changed.

## Decision

**Do not treat 4.05 → 3.2375/2.95 as an isolated mesh-export loss.** The 4.05 assessment applies to the selected source in Blender's studio presentation. The retained 3.2375 and 2.95 assessments concern native arena presentation and different independent review judgments. The matched raw GLB source in that same arena already has the dark ochre/red palette, small facial presentation and shell-over-face composition. Native adds real, proven material/normal/color drift and stippling, but those do not explain the entire discrepancy.

Recommend one bounded **authored-surface transport control**, described below, before further likeness edits. Its correction principle is to preserve the source's complete authored material contract, rather than compensate for several transformations by repainting the asset. This is a diagnostic correction candidate, not a proposed global style change or an appearance acceptance claim. If source-equivalent native surfaces still fail the original hero, stop transport work: the remaining problem is shared source/presentation, not another color/tint/filter parameter search.

## Source-to-runtime audit

1. **Color transfer is not a demonstrated gamma bug.** `selected-geometry-admission/build_selected_conch.py:15–17` explicitly converts authored sRGB triples to linear before setting both Blender diffuse and Principled Base Color. `selected-native-normals/export_native.py:220–237` copies glTF linear baseColorFactor without a second conversion. Independent GLB decode here verified SHA `21a6fd0d5e300c58952408913c69824228304141daab461fcb0122a388e27f1a`, 51 meshes, 95 primitives, 14 materials, all 14 double-sided, and roughness 0.7599999904632568. Warm chalk (.96,.70,.43) converts to the GLB factor within 2.98e-8. Do not apply a speculative gamma correction.
2. **Runtime deliberately replaces the authored surface contract.** Export packs all 15 parts as hard, eye=null (`export_native.py:270–287`), retaining double-sided flags only in its mapping sidecar. Practice selects `faceted:true` (`src/practiceContent.ts:36–47`); `AnimalFactory.ts:378–383` facets/merges; `lowpoly.ts:30–45` recomputes normals and applies per-triangle ±12% color gain. The selected graph uses toon, flat shading, .85 roughness and authored color × actor tint; compiler defaults to FrontSide (`compile.ts:1003–1034`). Source materials are Standard, .76 roughness, DoubleSide.
3. **Known changes are real but not sufficient explanations.** Prior independently verified runtime arrays retain all positions/skin indices/weights, while every legacy color component differs. Only 75 vertices/25 triangles have normal-direction changes >1°, despite 19,503 normal-component changes. `AnimalFactory.ts:602–603` adds actor tint. Combining captured tint with the previously exactly replayed jitter gives multiplicative ranges R .6775–.8621, G .6890–.8767, B .7119–.9058 relative to source linear albedo. These are albedo gains, not predicted display-pixel brightness or likeness scores. Flat-shading uses derivative normals, so restoring stored normals alone does not restore the source shading contract.
4. **The authored-color experiment already answered its question.** `conch-native-color-independent/results.md` verifies all 19,710 authored-color components, unchanged legacy channels and matched controls, yet candidate and baseline are visually near-tied. Its 2.95 score must not be converted into a measured regression from 3.2375. Do not repeat this color-channel-only experiment.
5. **Stippling has already been narrowed beyond conjecture.** Received-shadow ON/OFF/ON changed the operative shader and restored ON byte-identically. Fixed-rest tent versus PCF then removed conspicuous fine pattern while preserving received shadows (`conch-tent-shadow-independent/REPORT.md`). The complete filter replacement changed sampling together; no single random/bias term was isolated. The later playable review (`conch-public4-tent-attempt2-independent.md`) found no convincing upgrade at portrait scale and incomplete final reload visual corroboration. Retain PCF; no further filter sweep or global change follows.
6. **Presentation is a major confound, not export corruption.** Blender uses three broad area lights (650/350/800 power), an orthographic camera, 780×960 output and AgX (`build_selected_conch.py:253–259`). Arena comparison uses 402×874, perspective FOV 95°, distance ~6.482, directional+hemisphere light and the actual composer. `selected-native-view/camera-fit.mjs:8–25` chooses one conservative sphere-based distance/FOV admitting all nine cameras inside the room; it is a containment contract, not a matching hero composition. The original review measures only ~131–292 pixels character height. `comparison.mjs:24–26,39–63` truly loads source materials and synchronously shares root/camera/lights, making it a valid transport comparison but not a Blender-lighting reproduction.
7. **Toon changes more than palette.** `compile.ts:230–248,261–280,959–983` replaces directional/ambient responses; `presets.ts:609–660` adds face/shadow bands, terminator and rim, with shadeGrade=0 in the reviewed look. Same lights do not imply same material response. There is no evidence that the current actor material is intended to preserve the studio result exactly.

Create one isolated REST-only adapter in a new diagnostic directory, after the root releases the work boundary. No active Conch owner, common shader, exporter, current product, host policy or public asset changes.

- Keep the actual native skeleton, positions, skin arrays, dimensions, root and rest transforms. Clone only its render geometry for the diagnostic, and restore the original geometry/material references in `finally`.

Do not also multiply vertex colors: source materials already carry the factors. Explain remaining residuals rather than assigning quality points. If parity fails, diagnose the concrete mismatch and stop; do not tune by image MAE.

If it remains dark/face-obscured like raw-source, report that outcome as expected evidence that transport fidelity is insufficient.
