# Conch native shading diagnosis

2026-10-19. Read-only source and saved-attribute investigation; no render, deployment, active-source edit or acceptance change. Independent native likeness remains **64.75/100**; the separate source-model **4.05/5** judgment does not transfer.

## Verified drift and exact owners

1. **The payload carries original colors, but the native faceting stage changes them.** `art/driftwood-isle/approved-conch/selected-native-normals/export_native.py:219–237` copies glTF linear base-color factors and source normals; `pack_native` at 270–288 puts all 15 parts in `hard`, including eyes. `src/game/plugin/geometry.ts:1313–1382` admits/copies those arrays. Its strict packed-body schema has no `facetJitter` field. The unrelated GLB `bodyExtras` support at 627–668 does not apply here.
2. **Actual practice path enables faceting.** `src/practiceContent.ts:36–48` builds each species from `bodies.copy`, with `faceted: true`. `src/engine/entities/AnimalFactory.ts:350–385` merges its parts and calls `facetGeometry(procedural(), sp.facetJitter)`. `src/engine/models/animalGeometry.ts:7–25` assigns hard material group 1. Therefore no face receives the eye-group-2 jitter exemption.
3. **Exact color transform identified.** `src/engine/entities/lowpoly.ts:30–46` defaults to ±12% deterministic centroid-hash gain, applied equally to the three vertices of each face. Recomputed using JavaScript numbers and Float32-converted admitted positions/colors, this predicts **all 19,710 captured native color components exactly: zero mismatches, maximum residual 0**. Actual gains range **0.8801729085674742–1.1199506834080966**. This is certain per-face albedo drift, not a conjecture based on screenshots.
4. **Normals are overwritten, but directional changes are localized.** The same function calls `computeVertexNormals()` after de-indexing. Of 6,570 vertices, only 75 differ by more than 1°: shell 45 vertices/15 triangles, maximum 21.00295°; head 30 vertices/10 triangles, maximum 84.13827°. Every other part has maximum below .008°. The report's 19,503 changed normal components mostly reflect numerical normalization differences, not widespread new face directions. Flat-shaded graph lighting also computes planar shading normals; restoring a normal array alone does not establish restored appearance.
5. **Native instance tint is an additional measurable darkening.** `AnimalFactory.ts:595–603` sets the per-instance material color from tint. Captured native material is RGB **[0.7697310801828281, 0.7827579721645452, 0.8088117561279796]**. `src/shards/driftwood-isle/data/lookGraphs.json`, `looks.driftwood-creature`, multiplies `vertexColour` by `materialColour`, so native albedo receives both this tint and the face gain. The source comparison loads original GLB materials directly; it does not receive this actor tint.
6. **Material/light response is intentionally different.** That graph uses `model: toon`, `flatShading: true`, roughness .85, metalness 0. Source GLB uses Standard materials, roughness .76, metalness 0. `src/engine/render/graph/compile.ts:959–983,1003,1032–1034` selects the toon hooks/flat shading and FrontSide default; `graph/presets.ts:609–660` implements bands, shadow threshold, terminator, rim and ambient lift. Source primitives are double-sided; captured native material side is 0 (FrontSide). Equal scene lights therefore do not imply equal shading. Keep the shared lights unchanged.

The saved front source/native PNGs were inspected directly: native interior face/body stippling is visible. **Its fine pixel-scale cause is not isolated by this diagnosis.** The hash above is constant within each triangle, so it cannot alone generate sub-triangle speckles. Toon shadow response, different shading normals and overlapping/self-shadowed surfaces remain possible contributors; attributing all stippling to color jitter or normal recomputation would overclaim. Source and native already share broader geometry/pose departures from the concept.

## One bounded candidate: authored paint through the existing material graph

Prepare a separate, unaccepted native candidate with an extra Float32 vec3 attribute **`aAuthoredColour`**, copied exactly from each admitted part's original `colorsLinear`. Keep every existing channel, triangle order, position, normal, bone, skin index/weight and dimension unchanged. In a **candidate-only** copy of the existing creature graph, replace only the `paint` node with `{ "op": "attribute", "name": "aAuthoredColour", "type": "vec3" }`. Keep its tint multiplication, toon model, flat shading, roughness, side, emissive and lighting untouched. Mount this graph only in the isolated candidate product; do not change the shared `lookGraphs.json` or host.

This uses existing packed attributes (`geometry.ts:1320–1325`) and supported graph attributes (`src/format/materialGraph.ts:820–824`, `graph/compile.ts:719–723`), not an engine/schema exception or a group-2 disguise. The unchanged faceting function still runs; only the authored material chooses its declared paint channel. The new channel costs 78,840 uncompressed bytes for 6,570 vertices, before compression. Do not smuggle `facetJitter: 0` into strict metadata or alter global animal behavior.

Purpose: isolate the impact of unintended second-pass color variation while retaining genuine native toon presentation. It **will not** undo actor tint, restore source normals/backfaces, cure geometry, or guarantee removal of stippling or a higher likeness score. Inverse-jitter precompensation was also calculated but is not recommended: it requires 615 input components above 1 (maximum 1.10485) and couples the asset to the hash implementation.

Before judging the candidate: validate the unchanged normal/geometry/skin arrays and the extra channel after actual faceting; assert the graph contains the sole paint-node change; preserve existing native/source captures, score freeze and public playables; capture the same complete nine native REST views with paired roots/cameras/light state; independently assess native-first against the exact approved concept, then compare the source and retained native baseline. Keep unresolved stippling and all animation/gameplay/phone-performance acceptance open. A lower image difference alone is not a visual quality pass.
