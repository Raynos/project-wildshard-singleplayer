## Admission and build adapter

`scripts/build-conch-motion5-preview.mjs` is a separate opt-in adapter. It:

1. Verifies every current motion5 frozen file and the preserved original audit hash.
2. Calls existing strict `admitConchReadable`, retaining native canonical mesh,
   measured body metadata, payload and all motion4 source-admission checks. It never
   calls or repurposes motion4's reviewed-build permission.
3. Requires a new `wildshard.conch.motion5.reviewed-build-pin.v1` receipt with the
   root GO reference, exact independent review hash, current freeze and Node version.
4. Pins a conservative inventory of all `src`, `vite` and `lint` files, top-level
   build/QA script sources, package, workspace and lock manifests, real `practice.html`,
   FP arms and Rapier assets. Additions, deletions, byte changes and source symlinks
   fail closed. Package-link `node_modules` directories are excluded; this is a
   source/lockfile closure, not a forensic hash of every installed dependency byte.
5. Bundles the exact motion5 factory and passes only admitted native bodies through
   unchanged SDK preparation, sealed decision-line budget and product validation.
   The emitted named pose must equal the frozen numeric payload (canonical JSON
   comparison), have the correct content hash and occur exactly once.
6. Emits the exact product file inventory into the preview receipt. The app stage
   checks that inventory, SDK index receipt, source hash, native tuple, pose and build
   pin again, including after compilation. A source change during compilation fails.
7. Uses the same real `practice.html`, practice runtime, Rapier alias, virtual starter
   tables and isolated save namespaces as motion4. Only candidate admission/identity
   and output paths differ. Existing build-time asset-copy hooks are retained; no
   runtime callback, schema exemption, alternate combat architecture or preview-only
   pose implementation is introduced.

All acceptance flags remain false. Nonempty output directories are refused, output
parent symlinks are rejected, existing pins are never overwritten, and partial
failed builds remain in place. No source, old host or production assets are cleaned.
The full source inventory is deliberately conservative (7,628 files at preparation,
about 965 KB of compact hashes): unrelated source changes can invalidate the pin.
Finalize build/QA adapter changes before root pins; never edit an existing pin to
make a mismatch disappear. Preserve failed attempts before authorizing another one.

## Capture reuse limits

Existing `qa-conch-readable-motion.mjs` explicitly admits motion4. Changing its
`CONCH_QA_DIST` alone does **not** establish motion5 admission. Mounted motion4 QA
also has old identity/report assumptions. Neither is a motion5 capture command.
Keep those files and their prior results unchanged. A separately reviewed capture
wrapper must require this motion5 pin, preview and exact emitted host inventory
before and after running. No capture wrapper is supplied by this bounded task.

The passive observation functions, frame review and weighted-contact mathematics
may be reused after verifying their actual inputs and pinning them. Existing results,
scores, frame coverage, motion4 manifests, matched video and performance claims may
not be relabeled or carried forward. Capture actual motion5 bytes and preserve every
failed attempt. Use the approved browser executable through `scripts/browser-lane.sh`,
muted iPhone 16 Pro portrait emulation, a static built server, and no Site mutation.

Required new coverage: complete ordinary and counter cycles; true early guarded
windup hits around .10/.20 and late windup; counter preparation around .215;
active/recovery interruption; clock-zero stun and repeated hits; subsequent cycles;
approach/stop/resume; lethal onset/corpse; player defeat; Retry and isolated persistence.
Record authoritative pose inputs, real runner/behavior clocks, root/joint matrices,
and render/encoded cadence. Independently inspect every encoded frame and fresh
weighted world contact. No physical-phone, foot-planting, death-improvement or
four-star claim follows from these source checks.
