## Build and acceptance sequence

1. Reuse actual drafts and approved targets; preserve old sources and failed evidence.
2. Make complete, consequential model revisions. Review full silhouette and anatomy before isolated decoration.
3. Capture fixed, fully framed nine-view evidence using the repository half-dome convention. Explicitly normalize front orientation: Conch is +Y in Blender; the other three are -Y. Keep original reference and approximate hidden-view expectations distinct.
4. Independently score each complete model using the unchanged rubric. A single flattering hero view cannot establish the gate. Retain best reviewed candidate and below-target WIP honestly.
5. Establish explicit native/rig admission and visible motion. Exercise actual isolated arena AI, telegraphs, attacks, hit, death, loot and Retry. Record complete cycles and review frames with state/clock/world-transform evidence. Do not mutate persistent world progress.
6. Publish public-safe real renders and runtime evidence in the existing review Site, approved target left and actual result right. Promote playable only after actual tests; preserve the tested Puffer fallback.

No physical-phone performance or human-fun claim follows from cloud rendering. Likeness is one milestone; animation, gameplay, balance and broader shard coverage remain independently open.
