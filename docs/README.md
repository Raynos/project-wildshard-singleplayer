# docs/

What each file and folder here is. The rules for agents are in [AGENTS.md](../AGENTS.md).

## Engine, SDK and shards

- [ENGINE.md](ENGINE.md): the engine API (`@wildshard/engine`, `@wildshard/game`, `@wildshard/sdk`), the layers and their public modules
- [SHARDS.md](SHARDS.md): how to write a shard
- [SHARDFILE.md](SHARDFILE.md): Shardfile 0.x, the format a shard declares itself in
- [SDK-DEV.md](SDK-DEV.md): build and preview an author project
- [SCRIPT-ABI.md](SCRIPT-ABI.md): Script ABI v0, the Wasm interface shard scripts compile to
- [COMMONS.md](COMMONS.md): the build-time commons, content packs shared across shards
- [PLATFORM-AI.md](PLATFORM-AI.md): declared creatures and encounters (brains and spawns as data)
- [GRID-SIMULATION.md](GRID-SIMULATION.md): local simulation frames, the live grid and its neighbour shards
- [CONTENT-CACHE.md](CONTENT-CACHE.md): immutable, hash-addressed content on disk
- [STATIC-WORLD-MATERIALS.md](STATIC-WORLD-MATERIALS.md): static world materials and atlas packing for baked tiles

## Running and measuring

- [RUNNING.md](RUNNING.md): run it locally: setup, tests, debug URL parameters, capture scripts, the production URL
- [BENCH.md](BENCH.md): the load bench (`pnpm bench`)
- [ios-memory-watchdog.md](ios-memory-watchdog.md): the iOS Simulator native-memory watchdog (E261)
