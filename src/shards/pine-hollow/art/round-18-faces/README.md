# Pine Hollow round 18: faces (E304)

Codex front head-and-shoulders portraits (image_gen, edited from a crop of each round-11 reference) of the hamlet's
three people. Each is the input of a Hunyuan3D-2 bust (cutout → full shape + paint) that scripts/img2mesh/e304_faces.sh
grafts onto the shipped body at the neck, the portrait projected on the new face, the normal map re-baked.

- portrait-trader.jpg: Mott, the trader (fur hat, mackinaw, neckerchief)
