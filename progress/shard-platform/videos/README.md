# SHARD-PLATFORM milestone videos (SF60, G202)

Real-capture iPhone-portrait clips of real play (Chromium as an iPhone 16 Pro, muted, Settings ▸ Developer on), 540 px
wide H.264 at ~0.9 Mb/s, each ≤ 4 MB. Recorded with `grid-drive.mjs` (usage in its header) through `scripts/browser-lane.sh`
against a `scripts/serve-build.sh --head` build; each clip has a JSON receipt beside it (build id, cuts, the grid state at
every leg).
