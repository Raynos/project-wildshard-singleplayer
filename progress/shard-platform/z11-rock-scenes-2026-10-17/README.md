# One scene namespace and baked Driftwood rocks

Z2 scene handles now own the names used by living buildings. Pine Cabins
borrows the resident namespace, and Driftwood buildings, cover and castaways
use it too. SceneRef/ObservationRef rows contain ids rather than owner paths.
Identity-checked release lets a later figure owner retire its own publication.

The registered rock producer writes finished shore and small-rock draws plus
nine Explorer choices. It retains authored positions, normals, colors,
per-copy poses, parameters and boxes, 91 shore hulls, and original spheres.
The runtime rock-table hook, its producer and both runtime rock modules
are deleted.

`proof.json` records the source rulers, six host-bar tests with file/line
evidence, decoded geometry proof, 28 native views, cross-build pixel/draw/
triangle/GPU/collider comparisons, physics walk, frame readings and phone
boot. Desktop passes its absolute floor. Simulator absolute misses remain
visible beside the alternating parent/candidate nonregression comparison.
Generated GLBs and JSON are rebuilt from the registered producer.

Driftwood drops 89 measured shard lines; platform source adds 29. Nalati
receives 141 lines of existing geometryBake debt as its sole remaining user,
so the global shard delta is +52. The coordinator approved this chargeback
and queued W3 row N2 in `docs/plans/shard-platform/open-x-queue.md`.

Map publication follows G490: source only here; sp-x10 owns the official
refresh and strict post-bake product check in the next canonical window.
