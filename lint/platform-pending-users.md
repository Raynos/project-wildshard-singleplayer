# Pending platform users (G419)

A general, documented W1 platform feature may await a second real user in
W2 or W3. Each JSON entry names its defining module, optional exported
binding, later-wave shard, existing plan table row, documentation, and
`rechecked-by: "end of W3"`. An export entry excludes only that exported
span; omitting `export` excludes a sole-user module. Helpers remain charged.

The reader refuses missing exports, docs, later-wave rows, duplicate entries,
path escapes and shard-specific source. The JSON report lists excluded spans
as `pending second user`, with their lines and plan records. They are not
actual import-graph users. Source inventories and component totals include
only the remaining charged spans.

At the end of W3 remove every unresolved entry: any feature still single-user
then counts again. Card fields have no allowance; their real paired consumers
are being merged. The initial required-ground allowance is Driftwood's G384
admitted query lattice, approved by the coordinator and confirmed by its owner.
