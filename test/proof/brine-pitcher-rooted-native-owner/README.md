variant in `../brine-pitcher-native-owner/`. The two-strike repertoire is unchanged:
crown snap and bilateral side-head snap. All three heads participate. The original
three-strike source and failed thrown studies remain retained.

This explicit `anchored-held` death mode holds the exact lethal pose. It has no
fold, droop, throw or moving-part velocity claim. One fixed body owns all seven
unaltered source hulls and retains its existing corpse reservation until disposal.
It is a persistent solid WORLD obstacle, not a disabled collider or a no-corpse
shortcut. Default rigid mode and all resource caps are unchanged.

collider at its current transform, with two-way group filtering. It excludes only
the actor's exact retiring motor. Hull penetration refuses before logical damage,
motor retirement or resource allocation; touching within the existing numeric
transform precision is allowed. It does not step physics or relocate the root.

milestone, real compiled decision script, native pose/lifecycle and Rapier. They
exercise lethal pose continuity, full-source floor clearance, persistent obstacle
