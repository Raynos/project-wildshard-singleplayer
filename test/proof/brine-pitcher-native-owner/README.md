## Actual native tests

`test/brine-pitcher-native-owner.test.ts` compiles the real AssemblyScript guest,
uses `PracticeNativeActor`, borrowed decision authority, actual packed source,
real Rapier world, `NativeCorpseOwner`, and the existing fixed pre/step/post order.
Five tests pass: compilation without cap changes; both attacks, phases and damage;
repeated hits and lethal continuity, quiet reads and freeze; four physical trials;
and exact tell/active/recovery boundaries with all three heads' participation.

The physical measurement test records failure honestly; its green measurement
assertion is NOT a green contact gate. `contact-diagnostic.json` retains 1,920
fixed/render-interpolated full-source measurements and exact source hashes.
Every trial fails the existing 5 mm flat-floor threshold. Fixed and hull minima
agree. First tick penetrates 61.491 mm on the body owner in every trial; the
idle trial reaches 76.858 mm at tick 132. At that later failure head/lid animation
is already at its terminal pose. Frozen residual is approximately 1–1.45 mm.
The first tick's root rises 59.63 mm while body-owned geometry penetrates; with
bind-constant body locals this implicates physical root rotation of broad low
roots, not an independently animated lid or a skin/hull transform mismatch.

`first-contact-hp60.json` preserves the initial test fixture using 60 hp before
correcting the fixture to the source species' 150 hp. It is not the final fixture.
No geometry, solver, damping, CCD, timing, root lift, padding or budget was tuned.

A supported next source design is an explicitly anchored rooted-plant death,
using the normal native owner without a thrown physical corpse, preserving the
lethal-entry head droop. It needs its own contact, cleanup and fight/retry proof;
this study does not implement or accept that alternative.
