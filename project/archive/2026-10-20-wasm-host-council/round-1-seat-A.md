1. **Nine’s Jian — gap (A07–A08, A10–A11):** select 30 Hz under W9 → collect tick-stamped press/release edges → advance saved combo/window state → submit authoritative swept intervals → resolve identified contacts and damage → emit presentation-only hit-stop → evaluate the published swing at 60 fps; the plan specifies the rate but leaves the input, contact, timing and presentation contracts unresolved.
2. **Ridden moving platform — gap (A09, A13):** select 30 Hz for gameplay contact → read authoritative activation/rider observations → publish a motion segment → evaluate collider and rider movement at 60 Hz → draw the same trajectory → save/load segment phase, body and rider continuation; the required physical interpolation and migration are unspecified.
3. **Hostile upload — gap (A02–A03, A05–A06, A11–A12):** admit actual bytes → reject fuel bypass/recursion → exhaust an infinite loop safely → reject NaN and excessive commands atomically → reject foreign ownership/memory access → retain committed state and last-good visuals; separate unshared memories support the memory boundary, but admission, transaction protection and publication rules remain incomplete.
4. **Nalati storm — gap (A07, A10–A12, A15):** run deterministic weather policy at 10 Hz → publish timestamped targets/events → ease light presentation at 30 fps → accumulate correct time when view calls halve under sustained 2× slowdown → preserve sim behavior; current synchronous weather requests and the view clock/overload contracts lack a defined port.
5. **Forty animals — gap (A06, A10, A12):** gather forty capability-scoped observations → batch due 10 Hz brains → commit in deterministic order → smooth published poses each display frame → measure burst-frame total → degrade presentation while retaining bounded deterministic sim; neither the forty-binding budget nor fairness and worst-call behavior is specified.
6. **All existing scripts and old saves — gap (A04, A07, A13–A15):** inventory Nalati/Pine and every v0/v1 consumer → port math, synchronous requests and continuation → load pre-wave fixtures → switch formats once → delete old runtime users together; early deletion and missing memory/contract decoders currently prevent this sequence.
7. **Desktop save on phone mid-fight — gap (A02, A07–A08, A13, A16):** restore complete logical/world continuation → restore pending inputs, staged commands and queries → replay the same tick-indexed command tape → compare contacts, RNG and state across engines; the plan’s arithmetic restrictions and quantized replies do not yet establish identical fight continuation.
8. **H0 on Jake’s phone — gap (A01, A17):** tap one benchmark link → run automatically → warm up and measure representative boundary, rewind and full-host workloads → upload build-labelled results → revise priorities if imports are cheap; the page, reporting destination and interpretation rules are absent.

Verdict: Keep W1 and the 10/30 Hz sim plus display-rate view direction, but the plan is not build-ready until it specifies protected transactions, authoritative contact timing, complete migration and measurable cross-device and phone-budget gates.
