ONE LINE
Project Wildshard is a browser MMO where every shard of the world is built by a player in Claude Code.

ONE PARAGRAPH
Project Wildshard is a first-person sandbox MMO that runs in the browser on desktop and phone. Its world is a grid of 500-metre shards, and every shard is built by a player: authors describe a world to their own Claude Code, which builds it with the Wildshard SDK, and upload it to the shared grid in an in-game ritual. Seven single-player shards already run on the engine, each in its own look, from a toon island to a painterly steppe and a neon city stacked 500 metres high.
